# climate_change_trend_analysis_
Title : Climate Change Trend Analysis and Forecasting 
Overview : This project analyzes historical climate data to identify long-term trends and forecast future climate patterns using data analysis and predictive modeling techniques. It involves preprocessing climate datasets, performing exploratory data analysis (EDA), visualizing key indicators, and applying forecasting methods to understand changes in climate over time.

The project involves:
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Visualization of climate indicators
- Greenhouse gas emission trend analysis
- Forecasting future emission patterns using time-series models

## Dataset Source
The dataset used in this project is obtained from Our World in Data (OWID): https://github.com/owid/co2-data

The dataset contains historical information about:
- CO₂ emissions
- CO₂ per capita
- Methane emissions
- Nitrous oxide emissions
- Total greenhouse gas emissions
- Country-wise and global climate indicators this much readme is not enough
